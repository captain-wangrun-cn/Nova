### 1.4 Agent 通读记录（2026-09-25，D45 的依据）

逐条读 `reports/baseline-outputs.jsonl` 的 6 条 `completion`（3 个 prompt × 4bit/8bit）：

| 输出 | 观察 | 判定 |
|---|---|---|
| rp-01 4bit | 第三人称过去时、感官细节足；Elara 从"挡路的人"旁边走进仓库，与"blocking the ramp"轻微矛盾；结尾截断 | 可用 |
| rp-02 4bit | 情绪压力写得到位；出现"didn't move / didn't speak"同款句式；结尾截断 | 可用 |
| **rp-03 4bit** | **越界**：整段聚焦买家，直接写出买家对白（"Forty percent. That's all I'm asking."）和动作，没有 Elara 的反应；违反 system prompt 的 "Never write the user's dialogue, thoughts, or actions" | **不可用** |
| rp-01 8bit | 引入 cargo van；同段两次写"the ramp groaned under the weight of the van's tires"；"She didn't move. Didn't speak."同款句式 | 可用，但复读更明显 |
| rp-02 8bit | 自创 lab / cover-up 阴谋，偏离 prompt 的"manifest / Kessler"场景；"She didn't look up. She didn't need to."同款句式 | 可用，但剧情自创 |
| **rp-03 8bit** | **同 4bit 的越界**，且"and I'm not even mad"与场景语气不符，"like wet wool"比喻突兀 | **不可用** |

**通读结论（Agent 主观判断，非用户评分）：**

1. **6/6 英文流畅、第三人称过去时、无中文/拒答/复读循环；5/6 可用。** 失败集中在 rp-03 的**角色边界**，不是基座的英文能力。
2. **量化不是主因**：rp-03 的 4bit/8bit 同样越界，rp-01 的 8bit 反而更复读。不要用"换 8bit"解决 RP 质量问题。
   - 机器 8-gram 复读率 0.0% 与人工看到的模板句复用不矛盾：它只抓连续 8-gram，抓不到跨段落的句式复用。
3. **S5 蒸馏新增两个目标**：① 角色边界，只写模型自己角色的对白/动作/心理，不代写用户角色；② 反 AI 味，清洗"didn't move / didn't speak / silence was thick / like a stone/thread"这类模板化句式。
4. **D19 收口为不换基座**（D45）。若用户后续复读改变判断，仍按上面的 ≥2/3 触发线重估。

### 2.3 S5 第一步的具体动作（管线通过的定义）

0. **先做 10 步训练 spike（D46，当前动作）**：装/验证 LoRA 栈 → 写训练入口（labels → loss、梯度检查点）→ 用几条合成英文样本跑 10 步 → 记录显存峰值 / step 时间 / `clocks.sm`。**这一步不碰蒸馏、不找数据集**；通过后再进入下面的管线步骤。
1. **定数据格式**：对话样本 + 记忆读写样本 + 工具调用样本各一条 schema（`docs/08-data.md` 第 213 行那张表已给每类 200 / 500-1000 的配额）；
2. **写生成脚本**：调教师 → 落 JSONL → 清洗（去思考段 / 去拒答 / 去超长）；
3. **写训练入口**：QLoRA + 英文数据，先只跑 **10 步**确认能跑；
4. **写评估回路**：拿 `qa-03`（唯一有客观答案那题，见 S2 报告）当固定对照点，加上 3 条 RP 的复读率/中文占比（`probe_rp_quality.py` 已能算）；
5. **跑满 500-1000 条**，产出 `reports/s5-pipeline.md`。

> 上面 5 步全部在**本地 4060** 上可完成。真正的规模化训练（步骤 3 的放大版）才需要 Kaggle / 云。
